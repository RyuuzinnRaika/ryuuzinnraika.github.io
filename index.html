01 / PROFILE

私について.

はじめまして。Ryuuzinn Raika です。

工業高校で電気分野を学び、石川県にある工業系大学へ進学しました。現在は情報技術を学びながら、ソフトウェアやネットワークに関するものづくりをしています。使って終わりにするよりも、「この裏側はどうなっているんだろう」と考えて、実際に作ったり調べたりするのが好きです。

通信の設計から使い勝手の細かな部分まで、興味は少し広め。新しい技術を知ったり、難しかった仕組みが理解できたり、「これなら自分でも作れるかも」と思える瞬間が好きです。完成したものだけでなく、途中で見つかった課題や試行錯誤も大切にしています。

いま石川県内の工業系大学・学部4年生
よく触るものRust / Python / Kotlin / C#
好きなこと仕組みを調べて、再現すること
息抜きゲーム・きらら系の日常アニメ
好きな色スカイブルーと淡いパステル

02 / HISTORY

これまでの歩み.

気になったことを、
自分で確かめてきた記録。

最初から今の分野に絞っていたわけではありません。パソコンへの興味から始まり、電気、ゲーム制作、そして自宅サーバーの構築へと、作りながら関心が広がっていきました。

  1. 中学時代
    はじまり

    パソコンの中身が気になる

    情報工学や論理回路に興味を持ち、コンピュータがどう動くのかを知ることに熱中していました。

  2. 高校時代
    学び

    工業高校で電気分野を学ぶ

    工業高校では電気分野を学び、資格・検定の取得にも取り組みました。美術部では、仲間を通じてゲームの絵に触れる機会もありました。

  3. 2023進学
    進学

    石川県内の工業系大学へ

    工業高校での学びを土台に、大学では情報技術をさらに深く学び始めました。

  4. 2023
    大学・課外活動

    サークルでゲーム制作

    大学で情報技術を学びながら、サークル活動などでゲームづくりに取り組みました。

  5. 20249〜12月
    自宅サーバー・ネットワーク

    自宅にVPNサーバーを立て始める

    Raspberry PiでSoftEther VPNの構築に挑戦。離れた場所から自宅のネットワークにつなぐため、VPN、NAT、DHCP、ルーティングを調べながら設定しました。12月にはVPN経由でのインターネット疎通も確認。Minecraftやファイル共有への接続も試していました。

  6. 2024予選
    技術コンテスト

    ICTSC予選に挑戦

    ICTトラブルシューティングコンテストの予選に参加しました。この年は予選敗退。結果も含めて、当時の技術的な挑戦として記録しています。

  7. 20258月
    学外での経験

    5日間のインターンシップ

    東京で5日間のインターンシップに参加。大学の外で実際の仕事に触れる機会になりました。

  8. 20263月
    技術コンテスト

    ICTSCに出場

    ICTトラブルシューティングコンテストに出場。Linuxやネットワークの設定、名前解決、経路制御などの技術課題に取り組みました。

  9. 2026研究
    研究

    故障に強い認証の仕組みを考える

    一部のサーバーが動かなくなってもログインを続けられる仕組みをテーマに、分散認証方式の実装と検証を進めています。

  10. 現在2026
    これから

    学部4年生。次は大学院へ

    大学院への進学を予定しています。研究だけでなく、Rustやアプリ開発、XRなど、興味を持ったものを引き続き作っていきたいと思っています。

ほかにも

PCの組み立てやゲーム機の修理、Arduino・Raspberry Piでの電子工作、3DやVR関連の制作などにも触れてきました。
