# Ryuuzinn Raika — Personal Website

[GitHub](https://github.com/RyuuzinnRaika) での活動を紹介する、静的な個人サイトです。

## 特徴

- 日本語中心の、読みやすい1ページ構成
- きらら系の日常アニメを思わせるパステル文房具風の配色（外部画像は使用しない）
- 中学・高校時代から現在までの経歴・活動年表を掲載（工業高校から石川県内の工業系大学、2024年のVPN構築・ICTSC予選を含む）
- 自宅サーバーの構成・用途と、保有・取得した資格・検定、顕彰を掲載
- PC・スマートフォン対応
- 6件の制作ノートと、カテゴリーで絞り込むフィルター
- 7台の仮想ノードの稼働・停止を操作できる概念デモ（研究成果の実測ではない）
- フレームワーク、ビルドツール、追跡タグ、外部フォント不要（バニラJavaScriptのみ追加）
- 公開リポジトリは実リンクを掲載。非公開リポジトリへのリンクは掲載しない
- 本人が指定したX公開プロフィールへのリンクと、本人が共有した趣味（ゲーム・きらら系日常アニメ・スカイブルー）を紹介
- 本人提供の過去のX投稿から、2020年のアイコン制作、2022年のゲーム、2023年の初めてのカレー作りを短い「日常のメモ」に整理
- 発見→試作→検証→次へ、の流れで技術への興味が伝わるようにする
- GitHub Pages（ブランチから公開）対応

## ローカル確認

`index.html` をブラウザーで開くか、Python がある場合はこのディレクトリで次を実行します。

```sh
python -m http.server 8000
```

`http://localhost:8000/` を開いて確認できます。

## GitHub Pages に公開する

1. GitHubで **`ryuuzinnraika.github.io`** という **Public** リポジトリを新規作成します（ユーザー名に大文字があってもリポジトリ名は小文字にします）。
2. このディレクトリのファイルを、新規リポジトリの `main` ブランチ直下にアップロードします。`.nojekyll` も含めます。
3. `Settings > Pages > Build and deployment` で `Deploy from a branch` を選び、`main`・`/(root)` を選択して保存します。
4. 公開完了後、`https://ryuuzinnraika.github.io/` にアクセスします。

### コマンド例（作成済みリポジトリに初回push）

```sh
git init
git add .
git commit -m "Create personal website"
git branch -M main
git remote add origin https://github.com/RyuuzinnRaika/ryuuzinnraika.github.io.git
git push -u origin main
```

※ コマンドは空のリポジトリ向けです。すでにREADMEなどがある場合は先にクローンしてください。

## 制作ノート・ミニ実験（2026-10-21 更新）

- 制作ノート: Rust製1.7.10サーバー、PDFと手書きの端末間連携、分散認証研究、自宅サーバー運用、XRインターフェース、過去のWeb試作の6件。本人の開発テーマと公開GitHubを元にした概要です。公開していないリポジトリはリンクしません。
- 絞り込み: 「すべて／インフラ／アプリ・XR／研究／Web」。JavaScriptが無効ならボタンを隠して全件を表示し、標準のdetails要素でメモを展開できます。
- ミニ実験: 仮想ノード7台の稼働状態をクリックで変更。教育用の仮定として4台以上の稼働で継続と表示します。**PBFTや実際の分散認証方式の正確な成立条件、認証成功率、実測結果を再現したものではありません**。
- JS無効時はノードボタンを無効化し説明を表示。外部ライブラリ・API・トラッカー・永続ストレージを利用しません。
- Rustサーバーは限定的な実装・検証段階で、Minecraft 1.7.10の通常サバイバル完全互換を主張しません。

### 手動確認手順

1. 制作ノートでフィルターを切り替え、全6件・インフラ2件・アプリ2件・研究1件・Web1件が表示されるか確認する。
2. 各メモの「難しいところ」などを開閉できるか確認する。
3. ミニ実験で3台を停止（4台稼働）なら継続、さらに1台停止（3台稼働）なら条件未達になるか確認する。
4. 「全台復旧」で7台の稼働に戻り、キーボードのTab/Enter/Spaceで操作できるか確認する。
5. JavaScriptを無効にし、6つのメモは読めること・ノード操作が誤動作しないことを確認する。
6. 320px/375px/768px/デスクトップで横スクロールや要素の重なりがないか確認する。
